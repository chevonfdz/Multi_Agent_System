The answer the customer sees

1. Customer and website

Only logged-in users can chat. Every question and reply is saved in app.db, so customers can return to old conversations and admins can review them.

2. Central router agent

The task planner works out which categories a question is about and creates one task per category, with filters such as price limits. Unclear questions get a clarifying question instead. The answer combiner merges the agents' results into one reply.

3. Domain agents

The food, clothes and electronics agents are specialists. Each searches only its own database, they run at the same time, and each has a 10-second time limit, so one slow or failing agent never blocks the others.

4. Databases

Each agent owns one SQLite database of text-only product data. app.db holds users, conversations, messages and a log of every agent call.

5. Daily refresh

Every day at 00:00 a scheduler tells each agent to scrape its own website list. The scrapers respect robots.txt and rate limits; if a site fails, its old data is kept.

6. Grounded answers

Products, prices and links come only from the databases, never invented. Product photos are loaded live from the shop when shown, and never stored.
